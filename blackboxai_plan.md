yes# Edit Plan — Fix UI visibility issues (SnapClass Streamlit)

## Information gathered
- `src/ui/base_layout.py` injects CSS that changes background colors but **does not consistently set text colors for Streamlit headers**.
- `header_home()` hardcodes header text color to `#E0E3FF` (light), which likely becomes low-contrast on the home background.
- Home page headings use `st.header("I'm Student")` / `st.header("I'm Teacher")`, but base CSS currently only targets `h1/h2` and not `h1` generated by Streamlit headers (likely to be default `h1` styling and/or overwritten by other styles).
- `teacher_tab_manage_subjects()` uses `st.header('Manage Subjects', ...)` which is reported as invisible (contrast issue).
- `src/components/subject_card.py` renders card content via HTML with explicit colors (so it’s likely mostly OK), but “button icons” appear broken/missing—this is likely due to Streamlit button/icon CSS not being styled consistently.
- Existing base layout CSS contains a likely typo: `line-height:1.1 1important;` which can break parsing, and only styles generic `h1/h2/h3` (not `stHeader` variants / `div[data-testid='stHeader']` blocks).

## Plan (by file)
### 1) `app.py`
- Add a single **global CSS override** for:
  - `h1, h2, h3` (Streamlit headings)
  - `div[data-testid='stHeader']`, `div[data-testid='stSubheader']`
  - `.card-title`, `.student-card`, `.teacher-card` if present
  - ensure text color is `#1a1a2e` and font-weight is bold for headings.
  - add button overrides for `button[kind="secondary"]`/`tertiary` to also keep icon visibility.

### 2) `src/ui/base_layout.py`
- Fix the typo in `line-height`.
- Extend CSS to explicitly set heading/text contrast inside Streamlit containers:
  - target `div[data-testid='stHeader'] span` (and similar) to enforce dark color.

### 3) `src/screens/home_screen.py`
- After applying global CSS, ensure the “I'm Student/I'm Teacher” blocks use dark text if not already overridden.
- Optionally wrap with a container class and apply `color: #1a1a2e` via `st.markdown` styles.

### 4) `src/screens/teacher_screen.py`
- Ensure `Manage Subjects` heading uses explicit color by adding a small per-screen style override before the heading.

### 5) `src/components/subject_card.py`
- Ensure internal icon text and any “button-like” elements inherit proper contrast.
- (If icons are inside buttons/dialogs) add CSS for Material icon spans to ensure their `color` is dark on white buttons.
